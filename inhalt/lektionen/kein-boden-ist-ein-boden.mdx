Du baust einen Ersatzweg ein: Findet der Abruf nichts Passendes, soll das System auf eine andere Quelle ausweichen oder ehrlich sagen, dass es die Antwort nicht hat. Der Code dafür ist eine Zeile — `if dokumente:` — und sieht nach Sorgfalt aus. Zwei Monate später fällt auf, dass dieser Zweig noch nie gelaufen ist. Nicht, weil der Abruf immer trug, sondern weil eine Ähnlichkeitssuche mit festem `k` immer genau `k` Treffer liefert. Die Liste wird nie leer. Der Wert, der etwas über die Güte gesagt hätte, wurde eine Zeile vorher weggeworfen.
